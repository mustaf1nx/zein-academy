## Серверные сценарии

Проверялись независимая сдача математики и физики; две пары одной группы за день;
повторный/параллельный POST; устаревшая версия; смена учителя; сохранение автора,
ставки, ID строк и времени создания при редактировании; запрет постороннему;
пустые/неполные/дублированные записи; оценки/тема/домашнее задание; чужой слот;
будущая и административная прошлая дата; заморозка и её позднее добавление;
изменённый состав группы; архивирование; преподаватель-администратор; разовая
замена без своих групп; отмены/переносы; месячный диапазон и границы штрафов;
неизвестные ставки; реальное bcrypt/JWT; закрытые диагностические endpoints;
атомарное изменение группы/расписания; постоянство ID неизменившихся слотов;
число SQL-запросов списка; повреждённый старый интервал расписания.

Отдельно проверены миграция схемы из исходного архива, сохранность старых строк,
неизвестный/смешанный автор и дубли, повторный запуск миграции, создание админ-преподавателя
только основным администратором, запрет другим админам управлять админскими аккаунтами,
подписанные ссылки с истечением срока/областью действия, запрет использования
приглашения как входа сотрудника и области доступа к характеристикам.

Модель старой схемы хранится в `tests/fixtures/legacy_schema.sql`; это структура
таблиц без пользовательских данных. Фикстуры создают собственные тестовые записи.
Тест гонки использует два потока: одна отправка получает успех, другая конфликт,
в базе остаётся один оплачиваемый урок.

## Браузер

Chromium действительно выполнял HTML/JavaScript приложения: вход, создание нового
админ-преподавателя из интерфейса основного администратора, два меню,
полчасовая сетка, кабинеты разных филиалов, фильтры, даты отчётов, личный журнал
администратора, сумма после сохранения, мобильный экран, два предмета,
запоздалый ответ первого журнала, сохранение формы после ошибки, переназначение
группы и сохранение двух слотов при редактировании.

В этой среде браузер не использовал реальную сеть. Для проверки интерфейса
`fetch` направлялся через тестовый транспорт в настоящий FastAPI TestClient
на изолированной SQLite-базе. Внешние шрифты исключались из тестовой страницы,
localStorage и часы фиксировались. Рабочие HTML-файлы этой подмены не содержат.

Это проверка связки интерфейса и логики API, **не** полноценная проверка боевого
сетевого пути: DNS, TLS, reverse proxy, CORS между доменами, тайм-ауты хостинга
и реальные сетевые гонки требуют отдельного запуска на staging. Проверка наличия
карточек на мобильном размере не является полным тестом всех мобильных экранов.

## Среда

Текущий прогон выполнен в изолированной среде Python/FastAPI/SQLAlchemy с
системным Chromium. В этой сессии сеть для `pip` была недоступна и пакет
`bcrypt==4.2.0` нельзя было установить, поэтому для тестового процесса использован
локальный совместимый stub только для операций hash/check. Рабочий код по-прежнему
импортирует и требует настоящий `bcrypt`, указанный в `requirements.txt`.

Изменения этой версии не затрагивают криптографическую реализацию `auth.py`; перед
production deploy зависимости следует установить обычным `pip install -r requirements.txt`.
Дополнительные extras Uvicorn и PostgreSQL-драйвер не являются частью доказанной
тестами сетевой/нагрузочной конфигурации. Исходный runtime хостинга Python 3.11.0
не запускался. Рабочая PostgreSQL-база и реальный домен не проверялись.

## Повторение

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m playwright install chromium
python tests/browser_smoke.py
```

Можно передать путь к уже установленному Chromium через `BROWSER_EXECUTABLE`.
Тесты переопределяют секреты и подключение до загрузки приложения, создавая только
временные базы. Не изменяйте их фикстуры так, чтобы они использовали production
DATABASE_URL. Бизнес-дата тестов зафиксирована: 24 сентября 2026 года.

## Что результат не доказывает

Тесты не доказывают корректность всех старых бизнес-правил, не восстанавливают
утраченные исторические авторства, не измеряют ускорение production, не являются
пентестом и не заменяют сверку реальных выплат. Непроверенные направления и
оставшиеся риски перечислены в `AUDIT_RU.md`.
